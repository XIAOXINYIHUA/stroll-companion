散步伴侣 隐私政策

生效日期：2026年6月25日 · 版本 1.0

散步伴侣（以下简称"本应用"）由个人开发者开发运营。我们高度重视您的隐私保护。本隐私政策说明了我们如何收集、使用和保护您的信息。

一、信息收集

我们不收集任何个人信息。本应用仅在本地设备处理以下数据：

1. 位置信息

用于获取您当前所在区域的天气和空气质量数据，并推荐附近散步路线。位置数据仅在应用运行时在本地使用，不会上传至任何服务器。

2. 网络请求

本应用通过 HTTPS 协议向 Open-Meteo 公开 API 获取天气和空气质量数据。请求中仅包含经纬度坐标和时区信息，不包含任何个人身份信息。

二、信息存储

所有用户数据（包括但不限于散步记录、偏好设置）均存储在您的设备本地，使用 HarmonyOS Preferences 本地存储机制。

我们不会将您的任何数据收集、存储或传输至远程服务器。

三、信息共享

我们不会向任何第三方出售、共享或披露您的个人信息。因为我们根本不收集它们。

四、第三方服务

本应用仅使用以下第三方公开服务：

  • Open-Meteo（open-meteo.com）：免费开源天气与空气质量数据 API，无需 API Key，不追踪用户。
  • 华为位置服务（Huawei Location Kit）：华为 HMS Core 提供，仅在本地获取设备位置。

您可查阅 Open-Meteo 的 服务条款 了解更多。

五、权限使用

本应用申请以下系统权限，均仅用于核心功能：

  • 位置 LOCATION + APPROXIMATELY_LOCATION：获取当前位置以推荐附近散步路线。
  • 网络 INTERNET：获取天气和空气质量数据。

您可随时在系统设置中撤回这些权限。撤回后相关功能将不可用，但不影响其他功能。

六、数据安全

由于本应用不收集或传输用户数据至任何服务器，不存在用户数据泄露、丢失或滥用的风险。所有数据仅存储在您的设备中，受 HarmonyOS 系统级安全保护。

七、儿童隐私

本应用不针对 13 岁以下儿童设计。我们不会故意收集儿童的个人信息。如果您是家长或监护人，发现您的孩子向我们提供了个人信息，请联系我们，我们将删除相关信息。

八、隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面公布，并更新"生效日期"。建议您定期查阅本页面以了解变更。
