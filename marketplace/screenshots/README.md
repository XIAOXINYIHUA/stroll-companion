# 应用截图

截图要求：
- 尺寸: 1080 × 2340 px (手机竖屏)
- 格式: PNG 或 JPG
- 数量: 3-8 张

## 获取方式

在 DevEco Studio 远程模拟器中运行应用后截取：
1. Tools → Device Manager → 启动模拟器
2. Run 应用
3. 在模拟器窗口点击截图按钮

## 文件命名

- 01_home.png — 首页（天气 + 路线推荐）
- 02_route_detail.png — 路线详情（评分 + 环境评估）
- 03_onboarding.png — 入场引导（生活方式选择）
- 04_walking.png — 散步中（地图 + 计时器）
- 05_discover.png — 发现页（分类标签筛选）
- 06_profile.png — 我的页面（统计 + 菜单）
